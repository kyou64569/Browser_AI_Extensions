会话列表

功能

🌐 网页翻译

翻译模式

🎬 实时字幕

观看外语视频时实时显示原文字幕与译文。优先读取平台内嵌字幕；无字幕的视频可选用 Whisper 语音识别。

Whisper 模型（可多选）

在“设置 → Whisper 模型配置”中添加模型后，可在此勾选用于语音转写。

📝 字幕总结

点「总结字幕」可基于下方勾选的字幕批量总结（未勾选则总结当前实时字幕），结果可在“总结管理”中批量下载。

💬 字幕管理

关闭字幕后会自动生成一条记录；可改名、展开查看完整内容，勾选多条可批量总结，也可单条删除。

📋 总结管理

总结结果按条展示；可改名、展开查看，勾选多条可批量下载，也可单条删除。

📚 知识库

选择一个知识库来源并填写凭证，之后在聊天框「＋」菜单中即可选择具体知识库进行提问。凭证仅保存在本地，不会上传到第三方。

设置

模型配置

备用模型配置（自动降级）

当前聊天模型调用失败时，按列表优先级依次尝试以下备用模型；温度 / TopP 等参数沿用失败的原模型。

Whisper 模型配置（字幕语音识别）

用于“实时字幕”功能中无平台字幕的视频语音转写。可配置多个（如两个免费额度模型），开启字幕时按顺序负载均衡、单个超额或失败时自动切换下一个。

多模态模型配置

用于聊天中的多模态任务（如生成图片 / 音频 / 视频）。勾选该模型支持的模态，AI 会自动按任务类型调用对应模型；未配置该模态模型时，AI 会提示你先配置多模态模型。

提示：在扩展侧边栏中可直接调用各厂商接口（含官方端点）；Ollama 等本地服务也支持浏览器直连。
